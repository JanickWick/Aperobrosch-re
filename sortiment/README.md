# Sortiment — fünf Abteilungen

Die Produkte bestimmt Wick. Jede Position steht genau in einer Abteilung:

- **Bäckerei** — Brot, Brötli, Apérogebäck aus der Backstube
- **Konditorei** — Pâtisserie, Torten, Desserts
- **Confiserie** — Pralinés, Schokolade, Truffes
- **Küche** — Warmes, Suppen, Menüs, Grill
- **Traiteur** — Belegtes, Canapés, Platten, Fingerfood kalt

Ein Eintrag: `{"name": "…", "beschreibung": "…"}` — mehr nicht. Bilder,
Mengen und Preise kommen später, Produkt für Produkt.

Die frühere Liste mit 97 Positionen liegt zur Referenz unter
`uebersicht/sortiment.json`; sie ist nicht mehr massgebend.
